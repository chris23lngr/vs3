## vS3

`vS3` is a TypeScript-first library for effortless S3 storage access. Skip the boilerplate and use exactly what you need. Framework-agnostic and feature-rich, it includes authentication, validation, signatures, and more.

Read the [documentation](https://vs3-docs.vercel.app/docs) for more information.
